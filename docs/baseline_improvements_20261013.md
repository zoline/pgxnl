## 4. 얻은 교훈

- **프롬프트 문구는 관계없는 문항을 흔든다.** 형태 문제는 코드 규칙(B)으로 고치는 게 안전하다.
- **같은 설정이면 결과가 재현된다.** "흔들림"으로 보이던 것 상당수는 실제로 설정 차이였다(용어집 조합, 캐시).
- **결함 판정은 데이터로 한다.** evidence 의 숫자·값 오기(Brasil, < 10, 'legal')는 실제 값과 대조하면 바로 드러난다.
- **용어집 끄기는 scope 로.** 레거시 enabled 열로 껐다가 측정이 오염된 사고가 있었다.
- **규칙·용어집 문구의 괄호를 조심한다.** `(cards.name = X)` 같은 괄호가 `= (서브쿼리)` 모양을 유도한 것으로 보인다.
